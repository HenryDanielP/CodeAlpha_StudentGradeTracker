# 🚀 NEXUS — Student Grade Tracker

> A modern Java-based student grade management application for recording student marks, calculating academic performance, and tracking grades.

## ✨ Features

- 👨‍🎓 Student information management
- 📚 Subject and marks management
- 🧮 Automatic total and average calculation
- 🎯 Grade calculation and performance evaluation
- 📊 Academic performance tracking
- ✅ Input validation
- 🔎 Student/record management
- 🎨 Clean and user-friendly interface

## 🛠️ Technology Stack

- Java 21
- JavaFX 21
- Maven
- Object-Oriented Programming
- Java Collections
- JavaFX UI
- CSS

git clone https://github.com/HenryDanielP/CodeAlpha_StudentGradeTracker.git
