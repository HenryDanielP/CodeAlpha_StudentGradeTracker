# 🚀 NEXUS — Student Grade Tracker

> A modern JavaFX application for managing student grades, academic performance, and classroom analytics.
---

## 📚 About the Project
NEXUS — Student Grade Tracker is a Java-based academic management application developed as part of the **CodeAlpha Java Programming Internship**.

The application provides a centralized dashboard for managing students, recording grades, calculating academic performance, and visualizing class-level statistics.


## ✨ Features

- 📊 Dashboard with student performance statistics
- 👨‍🎓 Add, edit, delete, search, and manage students
- 📝 Record and calculate subject grades
- 📈 Grade distribution and subject analytics
- 💾 Local CSV data persistence
- 🎨 Futuristic dark JavaFX interface

## 🛠️ Technology Stack

- **Java 21** — Core programming language
- **JavaFX 21** — Desktop graphical user interface
- **Maven** — Build and dependency management
- **ArrayList** — Student data management
- **LinkedHashMap** — Subject and grade storage
- **CSV** — Local data persistence
- **CSS** — User interface styling
